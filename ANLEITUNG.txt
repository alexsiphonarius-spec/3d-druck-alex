3D DRUCK ALEX – GitHub Pages Upload

1. Auf github.com/new ein PUBLIC Repository mit Namen 3d-druck-alex anlegen.
2. Im Repository Add file > Upload files wählen.
3. NUR index.html, config.js und robots.txt aus diesem Ordner hochladen (nicht die ZIP).
4. Commit changes klicken.
5. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
6. Nach einigen Minuten steht oben auf Settings > Pages die öffentliche Website-Adresse.
7. Test: Mit einem zweiten Gerät eine TESTANFRAGE schicken. Dann im Personalzugang anmelden und prüfen, ob sie erscheint.
